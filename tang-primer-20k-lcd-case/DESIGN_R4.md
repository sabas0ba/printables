# Tang Primer 20K LCD一体型ケース R4 設計書

## 1. 設計対象と外形

Tang Primer 20K Core装着済み公式Dock 3713と、公式4.3インチまたは5.0インチRGB LCDを一体化するFDMケースである。外形は140.00 x 112.00 x 53.80 mm。R3比でYを+20.00 mm、Zを+20.00 mm拡張した。座標はX=幅、Y=高さ、Z=表示面から背面とし、表示面をZ=0とする。

DockとLCDはY方向へ10.00 mm移動してケース中央を維持する。Dock原点はX=22.50、Y=14.50。公式Dock/Core STEPのZ位置は変更しない。

## 2. 背面サービス構造

背面は、外装を保持する固定フレームと、工具なしで外せるサービスキャップに分割する。

| 部位 | 寸法・固定 | 解除 |
|---|---|---|
| リアアクセスフレーム | 奥行22.00 mm、中央開口120.00 x 92.00 mm | ケース全分解時のみ4本の前面ピンを外す |
| リアサービスキャップ | 追加奥行20.00 mm、上フック2本＋下プッシュタブ2本 | 下タブ2本を内側へ押し、下辺を起こして上フックを抜く |
| PMOD配線出口 | 下辺に幅20.00 mmの開放切欠き2か所 | ケーブル接続状態のままキャップ着脱可能 |

ケース用スナップピンの係止面はZ=33.80 mmのままなので、ピン全長37.00 mmを維持する。サービスキャップだけを外しても、LCD、Dockトレイ、Dock固定ねじ、外装ピンは動かない。

サービスキャップは背面格子をベッド面として造形する。上フックと下タブはアクセスフレームの専用スロットに入り、係止突起はキャップ前端から3.00 mm突出する。下タブの舌片も3.00 mm突出する。上フックの舌片はフレーム上壁とY方向に重なるため、突出をフレーム背面板の厚さと同じ2.40 mmとし、背面板の内面で止める。係止突起はZ方向に連続的に成長する傾斜面で、サポートを要求する水平下面を設けない。

## 3. 各部の固定

| 対象 | 固定方法 | 解除方法 |
|---|---|---|
| LCD | 外形ポケット＋リテーナー＋PETG爪6本 | 左右爪、上爪の順に外す |
| Dock | 公式四隅穴＋M2.5 x 6なべ頭ねじ4本 | 4本を外して垂直に持ち上げる |
| Core | DockのSODIMM接点＋両側ラッチ | サービスキャップを外し、両ラッチを同時に開く |
| FPC | コネクタロック＋開放ガイド＋ポリイミドテープ | テープを剥がし、コネクタを解除 |
| 外装構造 | プリント製分割スナップピン4本 | フレーム側の二股をつまみ前方へ押す |

Dock支持部は7.00 mm角、高さ3.20 mm。公式87.00 x 65.00 mm穴ピッチ上に、2.00 mm角、深さ4.80 mmの止まり下穴を設ける。M2.5 x 6ねじの樹脂への公称ねじ込み量は4.410 mm、ねじ先端と穴底の公称余裕は0.390 mmである。

| STL | 数量 | 用途 |

| `lcd_retainer_43_snap.stl` または `lcd_retainer_50_snap.stl` | 1 | LCD外周押さえ |

## 5. Z基準と空間

| 基準面 | Z [mm] |
|---|---:|
| 表示面 | 0.000 |
| Dockトレイ前面 | 9.400 |
| Dock PCB下面 / 上面 | 15.000 / 16.590 |
| 公式Dock+Core STEP最大 | 30.165 |
| アクセスフレーム内面 | 31.400 |
| アクセスフレーム外面・キャップ接合面 | 33.800 |
| サービスキャップ内面 | 51.400 |
| サービスキャップ外面 | 53.800 |

中央開口部では、公式STEP最大面とサービスキャップ内面の最小公称すきまは21.235 mm。アクセスフレーム内面Z=31.400は中央が開口しているため、SODIMMラッチとPMOD領域を覆わない。

## 6. 造形

全STLは納品姿勢が推奨造形姿勢である。

| 部品 | ベッド面 | サポート条件 |
|---|---|---|
| フロントシェル | 表示面XY | 不要 |
| LCDリテーナー | XY平面 | 不要 |
| Dockトレイ | XY平面 | 不要。FPCガイドは上面開放 |
| リアアクセスフレーム | 背面フランジXY | 不要。壁は垂直 |
| リアサービスキャップ | 背面格子XY | 不要。係止突起は傾斜成長 |
| スナップピン | STL配置の横置き | 不要。二股がXY積層方向に沿う |

推奨条件はPETG、0.4 mmノズル、0.20 mm以下、外周4周以上、インフィル20～30%。サービスキャップのタブ部は0.16 mm、外周5周を推奨する。スライサーでは重複ボリュームの結合を有効にする。

## 7. 組立とサービスアクセス

1. `fit_coupon.stl`とスナップピン1本を造形し、嵌合を確認する。
2. LCD、LCDリテーナー、Dockトレイの順に重ねる。
3. Dockを4支持面へ載せ、M2.5 x 6ねじ4本を対角順に手締めする。
4. CoreをSODIMMへ挿入し、両側ラッチを閉じる。
5. FPCを接続・ロックし、開放ガイド上をポリイミドテープで押さえる。
6. リアアクセスフレームを重ね、前面からスナップピン4本を挿入する。
7. サービスキャップの上フック2本を先に挿入する。
8. キャップ下辺を閉じ、下タブ2本が復元してクリックすることを確認する。

SODIMMまたはPMODへアクセスするときは電源を切り、下タブ2本を押しながらキャップ下辺を手前へ起こし、上フックを抜く。ケース用スナップピンとDockねじは外さない。

## 8. 合格基準

- 1:1 PDFの100 mmバーと20 x 20 mm枠が定規と一致する。
- Dock穴4か所が支持ボス中心と一致し、締結後にPCBの反り・白化・割れがない。
- サービスキャップが上2か所、下2か所で完全に係止し、指で解除できる。
- PMODケーブルが下辺切欠きを通り、キャップとフレームの間に挟まらない。
- 3軸各10秒の軽い手振りで異音・部品移動がない。
- FPCに鋭角折れ、引張り、キャップとの干渉がない。
