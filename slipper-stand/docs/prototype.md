# スリッパスタンド試作 v0.3

## 変更点

- ねじとナットを廃止し、印刷した二股の抜け止めピン26本で固定する。
- 接着剤は不要。ピン先端をつまんで押し戻すと分解できる構造。
- ベース外周は公称R5、ソケットはR3、支柱・横桟・継ぎ板・支持具はR2で外縁を丸める。
- 支持具の先端は平面形状R25、板厚方向の縁はR2。
- ピンの頭と先端は約R0.45。角穴の輪郭も丸め、穴口を0.3 mm面取りする。
- ベースの不要なねじ穴を削除。
- 前後2面・2段、4足収納、設置面積280×250 mm、高さ約650 mmを維持。

すべてCADの公称値。曲面はSTLで多角形近似されるため、測定値には微小な差がある。
印刷用STLは最下点をZ=0へ補正済み。
印刷後の糸引き・バリや荒れた面はCADの丸めだけでは解消しないため、実物を確認する。

## 収納条件

左右1組×前後2面×上下2段＝4足（スリッパ8個）。靴底を中央へ向け、甲を外側へ向ける。
後ろ側も取り出しに使うため、前後にアクセス空間が必要。

| 項目 | 公称値 mm |
|---|---:|
| ベース | 280×250 |
| フレーム高さ | 636 |
| スリッパ込み高さ | 650 |
| 段間隔 | 310 |
| 仮想スリッパ・片足 | 長さ300×幅120×厚さ80 |
| 左右／上下の外形隙間 | 10 |
| 前後の靴底内向き面間隔 | 90 |

表示スリッパは外寸確認用で、履き口・内布・柔軟性を再現しない。
支持具下端からかかとまで8 mm、つま先まで308 mmを仮定している。
現物の停止位置が異なる場合、床離隔や上下隙間も変わる。

## 最初に印刷するもの

1. pin26.stl と coupon06.stl を各1個印刷する。
2. ピンの二股先端から試験片の穴へ押し込む。頭が当たり、反対側で二股の肩が広がるか確認する。
3. 頭を軽く引いて抜け止めが働くことを確認する。
4. 二股先端をつまんで押し戻し、外せることを確認する。白化、亀裂、永久変形がないことを確認する。
5. 固すぎる場合はcoupon08、緩すぎる場合はcoupon04で比較する。
6. 使用する隙間が0.6 mm以外になった場合は、src/stand.scadのclearanceを変更して本体も再生成する。
7. 接合試験に続いてholder.stlを1個印刷し、スリッパへの適合を確認する。

試験片の数字は角軸8 mmに対する穴の全幅方向の隙間。0.6 mmなら片側0.3 mm。
試験片が良好でも、長いピン・複数部品を重ねた接合は追加確認する。
一度に本体とピンを全数印刷する前に、試験片で条件を確認する。

## 印刷条件

単位mm。推奨印刷姿勢をSTLに反映済み。ピンは二股の曲がる方向を積層面内に配置する。
初期スライス案はPLA、0.4 mmノズル、0.2 mm積層、壁5周、上下6層、充填30%。
ピンは100%充填から試す。本体とピンに異なる条件を設定する。
これは未スライスの開始条件であり、所要時間・材料重量は未算出。
ピンの弾性・繰り返し寿命は実物で確認する。PLA等の材料名だけで保持力を保証しない。

大きな張り出しを避けた印刷姿勢だが、横向き角穴には8 mm程度のブリッジがある。
丸めた底縁の接地と薄板の反りをスライサーおよび実印刷で確認する。
ピンの二股の隙間へサポートを入れない。

部品は設計上の造形範囲320×310×315 mm以内で検査する。
この値はプリンタの機種仕様を保証するものではない。
支柱の長辺310 mmをプリンタX方向に置くとブリム余裕を取りやすい。
実機のBambu Studio設定で最終確認する。

## 組立

1. ベース中央ソケットに最下段の支柱を挿入する。pin40を2本、片側から差し込む。
2. 支柱2本を突き合わせ、後面に継ぎ板を当てる。pin28を継ぎ板側から4本差し込む。
3. 各段の前後横桟で支柱を挟み、中央の2穴を合わせる。pin52を後ろ側から各段2本差し込む。
4. 支持具を横桟に左右1個ずつ配置する。pin26を横桟の中央側から外向きに、各支持具2本差し込む。
5. すべてのピンで頭が着座し、反対面から出た二股の肩が広がっていることを確認する。
6. 必要ならベース左右のトレーへ重りを置き、別途脱落しない方法で固定する。
7. 最下段から収納と取り出しを確認し、片側だけ収納した状態も確認する。

分解時はスリッパを外し、対象部品を支えた状態でピン先端をつまんで押し戻す。
ピンを抜かずに部品を強く引き離さない。
ピンは弾性変形する消耗部品として個別交換できる。

## 検証範囲

- 印刷部品ごとに閉鎖性・単一連結・正の体積・外寸・底面位置を機械検査する。
- 靴底と組立モデルのブーリアン交差に面・体積がないことを確認する。
- 装着後のピンと本体に体積干渉がないことを確認する。
- ピン挿入中の弾性変形、引き抜き保持力、繰り返し疲労、長期クリープは未検証。
- 実物スリッパへの適合、耐荷重、転倒安定性、実印刷は未検証。
- ピン肩の位置と穴の寸法を設けた試作であり、実用上の抜け止め性能を保証するものではない。
- 甲の簡略形状は内部空洞を正確に表していないため、甲との適合は現物で確認する。

## 再現環境

既存OpenSCAD 2021.01とPythonを使用。追加インストールなし。
dotfilesのCLAUDE.md、AGENTS.md、docs/development.md、flake.nixは初版で参照済み。
この環境にはNixとDockerがなく、指定Nix環境での再生成は未検証。
ソースは本リポジトリのslipper-stand/src/stand.scadで管理。

build.pyはPython標準ライブラリのみ。render.pyは既存numpyとmatplotlibを使用。
validation.jsonに外寸・ソリッド体積・SHA256、environment.jsonに使用環境を記録する。
ソリッド体積はスライス後の材料使用量ではない。
