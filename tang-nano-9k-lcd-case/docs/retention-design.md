# Tang Nano 9K + RGB LCDケース 固定・組立設計書

## 1. 適用範囲

本書は、Tang Nano 9KとSipeed推奨の40ピンRGB LCDを収納するパネル組込みケースについて、部品固定方法、組立順序、荷重経路および設計公差を定義する。LCDごとの寸法は設計プロファイルとして`tools/profiles.py`に定義し、本書では次の2種類を扱う。

| プロファイル | LCD | 外形 | 表示領域 |
| --- | --- | --- | --- |
| `4p3in` | HT043DA-V.0、4.3インチ480×272 | 105.50 x 67.15 x 2.90 mm | 95.04 x 53.856 mm |
| `5p0in` | SH500J01Z、5インチ800×480 | 120.70 x 75.90 x 3.05 mm | 108.00 x 64.80 mm |

対象形状はリビジョン5とする。リビジョン4に対し、次の変更を加えた。

- LCD依存寸法をプロファイルへ分離し、5インチ版を追加した
- リアカバーのラッチ爪を、シャーシ受け穴と同じ基準から配置した
- リアカバー背面板をシャーシ後端に当てる構造とし、前後方向の位置を背面板で決めた
- 基板端部ストッパーとシャーシ上下壁の干渉を、壁内面の逃げ溝で解消した
- 4.3インチ版のFPCの向きを、データシートに基づきケース上側（HDMI側）へ訂正した

リビジョン4で解消した次の問題は、引き続き対象とする。

- Tang Nano 9Kがレール内で長手方向に移動する可能性
- リアカバーを取り付けるまでLCDリテーナーが固定されない構造
- USB-CおよびHDMIの挿抜荷重が基板とコネクタ半田部へ伝わる構造
- リアカバーを外した際にLCDと基板が同時に緩む構造

## 2. 構成部品

| 部品 | 機能 | 固定対象 | 固定方式 |
| --- | --- | --- | --- |
| フロントシャーシ | パネル固定、LCD位置決め | 既設パネル、LCDリテーナー | パネル用爪、リテーナー受け穴 |
| LCDリテーナー | LCD外周の保持 | LCD、フロントシャーシ | 4本の独立カンチレバーフック |
| リアカバー | 背面閉鎖、基板保持 | Tang Nano 9K、フロントシャーシ | 基板スナップ爪、外装ラッチ、シャーシ後端への当たり面 |
| Tang Nano 9K | 制御基板 | リアカバー | 固定ガイド、弾性爪、端部ストッパーまたはコネクタ隔壁 |

LCD、LCDリテーナー、基板およびリアカバーは、それぞれ独立した固定状態を持つ。リアカバーを外してもLCDリテーナーはシャーシに残り、基板はリアカバーに残る。

## 3. LCDおよびリテーナー固定

### 3.1 位置決め

| 項目 | `4p3in` | `5p0in` |
| --- | ---: | ---: |
| シャーシ内のLCD外周隙間（片側） | 左右1.25 mm、上下1.93 mm | 0.55 mm |
| リテーナー外形 | 107.60 x 70.60 mm | 121.40 x 76.60 mm |
| リテーナー開口 | 97.00 x 56.00 mm | 111.70 x 66.90 mm |
| リテーナー板厚 | 2.00 mm | 2.00 mm |
| FPC逃げ | 上側、幅25.00 mm | 下側、幅54.00 mm |

LCD表示面をフロントベゼル側へ向け、FPCをリテーナーの切欠き側へ通す。FPCが出る辺は、データシートの外形図で表示領域の余白が大きい辺である。

- HT043DA-V.0: FPC側の余白9.25 mm、反対側4.04 mm。FPCはケース上側（HDMI側）
- SH500J01Z: FPC側の余白7.76 mm、反対側3.34 mm。FPCはケース下側（USB-C側）

SH500J01ZのFPCは、幅広の部品実装部（幅約52 mm）がLCD外形から約5.9 mmの位置にある。FPCを背面へ折り返しても部品実装部がリテーナーに乗らないよう、切欠きはこの範囲に約1 mmの余裕を加えた幅とする。

リテーナーの平面部はLCD背面外周を支持し、表示領域へ直接荷重を加えない。

### 3.2 独立スナップフック

リテーナー左右に各2本、合計4本の後方延長フックを設ける。

| 項目 | 設計値 |
| --- | ---: |
| フックアーム厚 | 1.20 mm |
| フックアーム幅 | 6.00 mm |
| 全高 | 6.50 mm |
| 自由長 | 約4.50 mm |
| 最大掛かり量 | 0.60 mm |
| ランプ段数 | 3段 |
| シャーシ受け穴高さ | 0.80 mm |

フック頭部は0.00、0.20、0.60 mmの3段ランプとする。リテーナーをLCD側へ押し込むとフックが内側へたわみ、シャーシ側壁の受け穴で復元する。左右各2本が掛かった状態で、リテーナーはリアカバーから独立して保持される。受け穴の高さ位置はLCD厚さから計算し、フック頭部の前後に各0.10 mmの隙間を設ける。

分解時は左右のフックを内側へ押しながら、リテーナーを背面方向へ引き出す。FPCを引張って取り外してはならない。

## 4. Tang Nano 9K固定

### 4.1 支持構造

- 基板外形基準: 70.00 x 26.00 x 1.60 mm
- 基板側面隙間: 0.25 mm/片側
- 基板長手方向隙間: 0.30 mm/片側
- 支持面高さ: リアカバー背面板の内面から7.00 mm

基板は4か所の支持棚へ載せる。部品面をLCD側、microSDソケット面を背面サービス開口側へ向ける。2.54 mmピンヘッダ実装基板は対象外とし、実装する場合は保持部の再設計が必要である。

### 4.2 横方向固定

基板左辺は2組の固定ガイドと固定リップへ先に差し込む。右辺を押し下げると、2本の1.20 mm厚カンチレバー爪が外側へたわみ、基板上面で復元する。

| 項目 | 設計値 |
| --- | ---: |
| 固定側リップ掛かり | 0.55 mm |
| 弾性爪厚 | 1.20 mm |
| 弾性爪数 | 2本 |
| 弾性爪最大掛かり | 0.55 mm |
| 挿入ランプ | 0.15/0.35/0.55 mmの3段 |

基板を外す場合は、右側2本の爪を外側へ押し、右辺を持ち上げてから左側固定リップから抜く。

### 4.3 長手方向固定とコネクタ荷重

`4p3in`は、USB-C側とHDMI側に各2個の端部ストッパーを配置する。ストッパーはコネクタ中心、基板取付穴および端部部品を避け、基板端面へ接触する。基板端からシャーシ上下壁までは0.50 mmしかないため、ストッパーは壁内面より0.10 mm外側まで達する。シャーシ上下壁の内面には、深さ0.20 mmで背面側へ開いた逃げ溝を設け、ストッパーとの間に全周0.10 mmの隙間を確保する。

`5p0in`は、LCDの高さで本体の高さが決まり、基板端からシャーシ上下壁まで3.50 mmある。LCDを背面から挿入する構造上、シャーシ内側へ壁を張り出すことはできない。このため、リアカバーの両端に厚さ2.00 mmのコネクタ隔壁を設ける。

| 項目 | USB-C側 | HDMI側 |
| --- | ---: | ---: |
| 隔壁幅 | 22.00 mm | 25.00 mm |
| 切欠き幅 | 12.40 mm | 16.40 mm |
| 切欠き底のz位置 | 22.80 mm | 23.40 mm |
| 隔壁先端のz位置 | 15.40 mm | 14.60 mm |
| シャーシ開口 | 15.00 x 9.00 mm | 23.00 x 12.00 mm |

隔壁は基板端から0.30 mmの位置にあり、内面が端部ストッパーを兼ねる。切欠きの幅と底の位置は、4.3インチ版のシャーシ開口と同じである。このため、プラグとコネクタの位置関係は4.3インチ版と同一になる。切欠きはLCD側へ開いており、コネクタを実装した基板をリアカバーへ押し込める。シャーシ上下壁の開口は、ケーブルのモールド部が隔壁の面まで入る大きさとする。リアカバー外周リムは、モールド部の通過範囲だけ切り欠く。

USB-CまたはHDMIケーブルの挿入時、荷重は次の経路で受ける。

1. コネクタシェル
2. 基板端面
3. 端部ストッパーまたはコネクタ隔壁
4. リアカバー
5. フロントシャーシおよびパネル

実機のコネクタシェル突出量は公式外形図で確定できない。量産前に実測し、ケース開口または隔壁切欠きと端部ストッパーが同時に接触して過拘束にならないことを確認する。

## 5. リアカバー固定

リアカバー外周の4か所のラッチは、フロントシャーシ側壁の受け穴へ掛かる。旧構造にあったLCDリテーナー押圧用の4本の長い支柱は廃止している。これにより、リアカバーの寸法誤差がLCDへ直接圧縮荷重として伝わらない。

ラッチ爪と受け穴の高さ方向位置は、いずれもシャーシ本体外形の下端から測った同じ値で定義する。リアカバーの座標へは、本体とカバーの外形差を差し引いて変換する。これにより、爪の全幅が受け穴に入る。爪の前面は受け穴の下縁に0.05 mmの当たり代を持つ。

リアカバー背面板の外形はシャーシ本体外形より片側0.20 mm小さい。背面板の内面がシャーシ側壁の後端（z=27.00 mm）へ当たり、前後方向の位置を決める。標準リアカバーの全奥行きは29.00 mm、基板背面から背面板内面までの空間は7.00 mmである。20 mm／30 mm版は背面板がシャーシ後方にあるため、外周8か所の柱を同じ後端まで延ばして当たり面とする。

## 6. 組立順序

1. 使用パネル厚に対応するフロントシャーシをパネル角穴へ挿入する。
2. LCDを表示面が前方になる向きでシャーシへ置く。FPCは`4p3in`では上側（HDMI側）、`5p0in`では下側（USB-C側）へ向ける。
3. LCDリテーナーのFPC切欠きを合わせ、4本すべてのフックが掛かるまで押し込む。
4. リテーナーが単独で外れず、LCDが前後・左右に移動しないことを確認する。
5. Tang Nano 9Kの左辺をリアカバーの固定リップ下へ差し込む。
6. 基板右辺を2本の弾性爪へ押し込み、両端が端部ストッパーまたはコネクタ隔壁の間に入ったことを確認する。
7. FPCをTang Nano 9Kの40ピンコネクタへ接続する。
8. USB-Cをケース下側、HDMIを上側へ合わせ、背面板がシャーシ後端に当たるまでリアカバーを押し込み、4か所のラッチを掛ける。

## 7. 材料・印刷条件

- 推奨材料: PETG
- PLA使用時: 爪の繰返し着脱を避け、試験用とする
- ノズル径: 0.4 mm
- 積層ピッチ: 0.20 mm
- 外周: 4周
- 充填率: 25%以上
- スナップ爪の積層方向: アーム長手方向に層間剥離面を作らない向きを優先する

寸法精度が不足する場合、最初に爪を削るのではなく、テストピースで水平穴補正、エレファントフット補正および材料収縮率を確認する。

## 8. 検証項目

| 試験 | 合格基準 |
| --- | --- |
| LCDリテーナー保持 | リアカバーなしで上下反転しても脱落しない |
| 基板保持 | リアカバー単体を上下反転しても基板が脱落しない |
| がたつき | 手振りでLCDまたは基板の衝突音が発生しない |
| USB-C挿抜 | 10回の挿抜後に基板位置と爪へ目視変形がない |
| HDMI挿抜 | 10回の挿抜後に基板位置と爪へ目視変形がない |
| カバー着脱 | 5回の着脱後に4か所の外装ラッチが保持され、背面板がシャーシ後端に接する |
| FPC保護 | 組立・分解中にFPCへ折れ、挟込み、引張りがない |
| ケーブル（`5p0in`） | 使用するUSB-C/HDMIケーブルのモールド部が開口を通り、プラグが奥まで挿入できる |

## 10. 正確なアセンブリ断面図

断面図は、STL生成に使用する直方体CSG（加算形状から減算形状を除く）を同じ座標で評価して描画する。切断座標はプロファイルの部品位置から計算し、各断面が対象形状を必ず通過するようにしている。

| 断面 | `4p3in` | `5p0in` | 実際に通過する主な形状 |
| --- | ---: | ---: | --- |
| A-A | X=53.20 mm | X=58.90 mm | USB-C/HDMI開口、端部ストッパーまたは隔壁、LCD、FPC経路、リアカバー |
| B-B | Y=25.00 mm | Y=28.00 mm | 基板支持棚、左固定リップ、右弾性爪、基板 |
| C-C | Y=17.20 mm | Y=17.20 mm | LCDリテーナー左右フック、段付き頭部、シャーシ受け穴 |
| D-D | Y=40.50 mm | Y=43.50 mm | microSDサービス開口、基板裏面空間 |
| E-E | Y=72.90 mm | Y=75.90 mm | HDMI側2穴、M2ボス、角形下穴、増設用背面空間 |

塗りつぶした断面形状は、STLと同じ設計値から生成する。このため、C-Cに描かれたフックやB-Bに描かれた支持棚は模式図ではなく、印刷形状の正確な交差断面である。D-Dでリアカバーが中空に見える部分は、microSDへ背面からアクセスするための19.00 x 46.00 mmサービス開口である。

一方、Tang Nano 9Kの公式2D外形図からは、USB-C/HDMIシェル突出量、microSDソケット高さ、両面の最大実装部品高さを確定できない。図面ではこれらを橙色の破線エンベロープとして分離し、印刷形状または確定寸法として扱わない。量産造形前に実基板を測定し、破線エンベロープを更新する。

### 10.1 断面で確認できる固定状態

- LCDはベゼル背面とリテーナー平面部の間にあり、C-Cの4本のフックでシャーシへ独立固定される。
- 基板下面はB-Bの左右支持棚へ載り、左固定リップと右弾性爪で上下方向を固定する。
- 基板長手方向はA-AのUSB-C側・HDMI側の端部ストッパーまたは隔壁で固定し、挿抜荷重をリアカバーへ流す。
- リアカバーを外してもLCDリテーナーはシャーシに残り、基板はリアカバー側に保持される。

## 11. HDMI側2穴のねじ固定

Tang Nano 9Kの取付穴はHDMI端子側の2穴のみを使用する。USB-C側に取付穴があるとは仮定しない。固定リップと弾性爪を残したまま、次の任意ねじ固定を追加する。

| 項目 | 設計値 |
| --- | ---: |
| 取付穴数 | 2穴（HDMI側） |
| 穴径基準 | 2.20 mm |
| 穴中心間隔 | 20.80 mm |
| 基板端からの穴中心 | 2.60 mm |
| 印刷ボス | 6.00 x 6.00 mm |
| セルフタッピング下穴 | 1.70 x 1.70 mm角 |
| 有効ねじ深さ | 6.00 mm |
| 推奨ねじ | M2x8 |

角形下穴は直交直方体CSGで再現可能なセルフタッピング用形状であり、四辺でM2ねじを保持する。ねじは基板のLCD側から挿入する。基板が反るまで締め付けてはならない。ねじを使用しない場合も、固定リップと2本の弾性爪だけで基板を保持できる。

## 12. 20 mm／30 mm増設空間

増設基板やピンヘッダを使用できるよう、基板背面からリアカバー内面までの空間が20.00 mmと30.00 mmになる2種類のリアカバーを用意する。

| STL | 基板背面からの空間 | ケース全奥行き |
| --- | ---: | ---: |
| `rear_cover.stl` | 7.00 mm | 29.00 mm |
| `rear_cover_clearance_20mm.stl` | 20.00 mm | 42.00 mm |
| `rear_cover_clearance_30mm.stl` | 30.00 mm | 52.00 mm |

いずれも、LCD、Tang Nano 9K、USB-CおよびHDMI開口の位置は標準版と同一である。リアシェル、支持柱および背面板だけを後方へ延長するため、コネクタ位置は変化しない。増設基板の外形、ピンヘッダ高さ、FPC曲げ半径および外部ケーブルの曲げ空間は実機で確認する。

## 13. 単一部品化と背面板の軽量化

`4p3in`のUSB-C側とHDMI側の軸方向ストッパーは、外周リムと体積を共有する支持壁で背面板へ接続する。`5p0in`のコネクタ隔壁は背面板から立ち上げ、外周リムとも体積を共有する。20 mm／30 mm版の当たり柱も外周リムと体積を共有する。これにより、各リアカバーSTLは独立した突起を含まない単一の連結部品になる。支持壁と隔壁はPCB外形の外側に置き、基板背面の増設空間を横切らない。

背面板の左右非荷重領域には、8.00 x 6.00 mmの貫通スロットを36箇所設ける。スロット間のウェブと外周枠を残し、PCB保持レール、M2ボス、外周リム、ラッチ、ストッパー支持壁および隔壁とは交差させない。この開口はSTLに明示されるため、印刷サービスが内部充填率を指定できない場合も材料体積を低減できる。内部充填を指定できる場合は、保持部周辺を低密度化しない。
